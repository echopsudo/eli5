# eli5

eli5 (Explain like i'm 5) provides quick useful information about a command and the "whys".

avalible flags for now:

-l or --list (eli5 -l)
- lists installed entries

# FAQ:
- Isn't this just reinventing the wheel?
Kinda, man and --help provides useful info, but some of them just don't get to the point, which is why I created this. 

# Planned features:
- eli5 entry installer (eli5 install xyz), eli5 install -a installs every entry
